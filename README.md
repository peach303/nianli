# 念黎 · 言字卡二改

这是我自己在用的「言字卡」二改版本，仓库名 `nianli`，浏览器标签和添加到桌面的名称用「念黎」。应用内仍然保留「言字卡」这个名字，方便认功能。

## 来源

- 原作：**言字卡**，作者 **言序**（小红书 @言序 1842523578 / 抖音 @言序 58334080131）
- 原作站点：https://yanxu233.github.io/jinzhierchuanyanzika/
- 原作仓库：https://github.com/yanxu233/jinzhierchuanyanzika

本仓库不是原作，是**二改**：保留原作的基础框架，参考并沿用了原作的卡牌聊天、转账、通话、字卡库等玩法，在此基础上做了自己的修改。原作者没有参与这个版本，也不为它背书。

## 这个版本主要改了什么

- 视频通话里也能确认收下对方发来的转账
- 聊天统计新增「转账」页：我转出 / TA 转入、已领取 / 未领取 / 已退还、最近转账
- 我发转账不再卡 20 万的上限，可以填更大的金额
- 衍生字卡页改成可展开 / 收起的小标题，默认收起；设置里的回复 / 转账概率也改成同样的折叠样式
- 浏览器标签和添加到桌面的名称改为「念黎」，应用内仍叫「言字卡」

## 怎么用

- 纯静态站，直接打开 `index.html` 就能跑；部署时把 `sw.js`、`manifest.json`、图标和 `dist/` 一起放上去。
- 数据只保存在当前浏览器的 localStorage 里，没有后端，也没有账号系统。换设备前先导出数据。
- 线上地址：https://peach303.github.io/nianli/
